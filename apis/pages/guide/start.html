Guide 02快速开始

仓库根目录本身就是一个可运行的示例：装依赖、起服务、改适配器。

Node 18+pnpmoipage dev server
01

安装与启动

terminal
pnpm i
npm run dev

# http://127.0.0.1:20000/

dev server 由 oipage 提供：同时起 mock 接口与前端页面，改代码热更新。 示例默认接本地 ollama（qwen3.5），也可以在 src/apis/chat.js 里换成任意 OpenAI 协议服务。

02

目录结构

tree
src/
├── apis/
│   └── chat.js          服务端接口：Agent + CreateTool 驱动 SSE
├── adapter/
│   └── ...              三个适配器的实现
├── runtime/
│   └── ...              会话列表与对话内容的 DOM 渲染
├── tools/
│   └── ...              后端工具 readPlain 与前端工具 showPlain
├── index.js             页面入口
└── style.css            示例样式

四个目录正对应框架的四块拼图：apis 是服务端编排，adapter 是数据接缝， runtime 是渲染接缝，tools 是工具定义。

03

最小装配

页面侧只需要一个 AuiPage，把适配器与运行时塞进去，剩下交给组件库或你自己的 DOM。

main.js
import { AuiPage } from "@auipage/core";

const page = new AuiPage({
    adapter,        // { ChatTransport, MessageHistory, ThreadList }
    runtime: {      // { ChatContent, ThreadList }
        ChatContent: chatContentRuntime,
        ThreadList: threadListRuntime
    },
    tools: []       // 前端工具，可选
});

page.start();

已经用 React 或 Vue 的话，直接用上层组件库省掉运行时： @auipage/react、 @auipage/vue。

04

服务端一侧

示例的 src/apis/chat.js 用 Agent + CreateTool 直接把对话结果写成 SSE：

src/apis/chat.js
import { Agent, CreateTool } from "@auipage/agent";
import { MessageStream } from "@auipage/core";

const ms = new MessageStream(
    data => res.write("data: " + JSON.stringify(data) + "\n\n"),
    () => res.end()
);
const ct = new CreateTool(ms);

const agent = new Agent({
    model: { model: "qwen3.5", apiKey: "ollama", baseURL: "http://localhost:11434/v1" },
    tools: [ ct.create(readPlain), ct.create(showPlain) ]
});

await agent.generate(messages);
