各包共用的 TypeScript 类型协议。零运行时代码、零依赖，只放跨包消费的类型。

位置packages/types
01

安装

一般不单独装，它随其他 @auipage/* 包一起进来；只想取类型时再显式安装：

terminal
npm install --save @auipage/types

全部是 .d.ts，编译后不产生任何 JS。

02

五个类型分组

来源文件导出说明
basic.d.tsJsonValue JsonObject MaybePromiseJSON 值与同步/异步联合类型
model.d.tsModelConfig模型配置（model / apiKey / baseURL）
message.d.tsChatRole ChatMessage ModelToolCall ToolCallFunction发给模型 / 模型返回的对话消息（OpenAI 风格）

03

两层消息，别混用

message.d.ts 描述的是模型线上消息：content 是纯文本，发请求、存历史用它。

stream.d.ts 描述的是页面流里的富片段：文本增量、思维链、工具调用事件，渲染用它。

两种形态
// 线上消息（发给模型）
{ role: "user", content: "南京今天天气怎么样" }

// 页面片段（流式渲染）
{ type: "text", text: "南京今天" }
{ type: "tool-call", id: "call-1", name: "getWeather", args: { city: "南京" } }
同一段对话在这两层之间要经过一次翻译，翻译发生在 @auipage/core 的运行时里 —— 这也是"实时流"与"历史回读"能共用一套渲染逻辑的原因。
