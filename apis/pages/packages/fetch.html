Package 08@auipage/fetch

跨端流式 fetch：Node 下走 http/https，浏览器下走原生 fetch + ReadableStream，自动适配；SSE 响应自动按事件缓冲解析。

fetch0.2.0浏览器 + Node
版本0.2.0
依赖无运行时依赖
位置packages/fetch
01

最小可用

client.js
import { fetch } from "@auipage/fetch";

fetch({
    url: "https://example.com/api/chat",
    method: "POST",                                  // 默认 GET
    headers: { "Content-Type": "application/json" },
    body: { message: "hello" }                      // 普通对象自动 JSON 序列化（0.2.0 起）
})
    .then(res => {
        res.on("data", chunk => console.log(chunk));
        res.on("end", () => console.log("done"));
        res.on("error", err => console.error(err));
    })
    .catch(err => console.error(err));

res 上还能读到 status、ok（2xx 为 true）、headers，以及 res.header(name)、res.cancel()0.2.0 新增。

02

四个事件

事件触发时机回调参数
data收到一段数据；SSE 模式下为每个完整事件的 data: 内容(payload: string)
end响应体读取完毕()
error网络、读取、超时或取消出错(err: Error)
http-error0.2.0 新增状态码 ≥ 400，先于错误体播放({ status, headers })

监听晚于 error 发生也能收到：error 会缓存一次终态并在注册时补发0.2.0 修复。

03

SSE 自动解析

响应头 Content-Type 含 text/event-stream 时自动开启，不需要任何配置：

  • 按空行（\n\n，也兼容 \r\n\r\n）切分事件，跨 chunk 的事件会自动拼接；
  • data 回调拿到的是去掉 data: 前缀的字符串，不会自动 JSON.parse；
  • 非 SSE 响应行为不变，data 拿到的是原始 chunk。
为什么强调"不自动 parse"：把解析权留给调用方，才能兼容带 [DONE] 结束标记、 多行 data:、以及非 JSON 的自定义格式。
04

非 2xx 与取消

  • 非 2xx 不进 catch0.2.0 改造：fetch() 仍 resolve，错误响应体照常经 data / end 投递；同时额外发一次 http-error，拿到状态码就能立刻判断失败，不必等 body 读完。
  • 超时0.2.0 新增：timeout（毫秒）到点自动中止并触发 error。
  • 外部取消0.2.0 新增：传 signal，或在拿到 res 后调用 res.cancel()。
client.js
const controller = new AbortController();

fetch({ url, method: "POST", body, timeout: 30000, signal: controller.signal })
    .then(res => {
        res.on("http-error", ({ status }) => console.warn("HTTP", status));
        res.on("data", chunk => console.log(chunk));
        res.on("error", err => console.error(err));
    });
05

这个包不是必须的

你的情况更合适的选择代价
只在浏览器跑原生 fetch + body.getReader()自己写 SSE 切包与 \r\n 兼容
只在 Node 跑undici / axios / 原生 http仍要自己处理事件边界
用官方模型 SDKopenai 等 SDK 自带的流式读取多一个依赖，少一层掌控
只要一次性请求原生 fetch 即可没有流式能力

它只在“同一份读取代码要跑在浏览器和 Node 两端”时值得用。单端项目，原生方案完全够。
