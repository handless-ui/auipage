Package 07@auipage/core

核心层：业务侧实现 Adapter 对接模型与存储，UI 侧实现 Runtime 负责渲染，AuiPage 把两者串起来，统一处理会话、历史、流式对话与入库。

core0.1.0AuiPageAdapterRuntime
版本0.1.0
依赖@auipage/types
位置packages/core
01

导出

导出类型作用
AuiPage构造器框架核心，管理 adapter / runtime、消息与会话状态
ChatTransportAdapter适配器基类对接模型对话接口，流式产出片段
MessageHistoryAdapter适配器基类历史消息的加载与追加
ThreadListAdapter适配器基类会话列表的增删改查
ThreadListRuntime运行时基类会话列表的 UI 渲染钩子
ChatContentRuntime运行时基类对话内容的 UI 渲染钩子
defineTool函数定义前端工具（description / execute / render）
generator函数把回调式异步流转成 AsyncGenerator
MessageStream构造器消息流封装（send / end），服务端配合 CreateTool 推 SSE
02

三个适配器

adapter.js
new ChatTransportAdapter({
    async *run({ messages, context }) { /* yield 片段 */ },
    response(name, data) { /* 工具结果回传 */ }
});

new MessageHistoryAdapter({
    async load(threadId) { /* 历史消息组 */ },
    async append(threadId, group) { /* 落库 */ }
});

new ThreadListAdapter({
    async list() {},       async new(firstGroup) {},
    async archive(id) {},  async unarchive(id) {},  async delete(id) {}
});

三个实例按固定 key 组合成 { ChatTransport, MessageHistory, ThreadList } 交给 AuiPage。

03

两个运行时

运行时是"状态到渲染"的翻译层，基类里只有钩子，具体实现由 UI 框架决定：

运行时钩子职责
ChatContentRuntime消息追加、文本增量拼接、工具卡片状态流转、清空与载入历史
ThreadListRuntime会话列表渲染、激活态切换、归档/删除后的界面同步
React 与 Vue 组件库就是这两个运行时的完整实现，所以它们只做"调 DOM/VDOM"， 真正的流程控制仍在 AuiPage 里，一份逻辑两种框架共用。
04

defineTool 与 generator

core.js
const tool = defineTool({
    description: { type: "function", function: { name: "getTime", parameters: {} } },
    execute() { return new Date().toLocaleString(); },
    render: props => node                 // 可选：交互组件
});

const stream = generator((push, end, error) => {
    source.on("data", push);              // 回调式 → AsyncGenerator
    source.on("end", end);
    source.on("error", error);
});
05

MessageStream

server.js
const ms = new MessageStream(
    data => res.write("data: " + JSON.stringify(data) + "\n\n"),  // send 的落点
    () => res.end()                                                 // end 的落点
);

它只做一件事：把"要推给页面的数据"抽象成一个可 send 的对象， 前端工具挂起时由 CreateTool 通过它把事件写进 SSE。因此换成 WebSocket 只要换这两个函数。
