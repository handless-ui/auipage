文档/参考/defineTool 与 generator

Package 14defineTool 与 generator

两个小工具：defineTool 省掉工具描述的多层嵌套，generator 把回调式异步流转成 AsyncGenerator。它们不含业务概念，单独也能用。

defineToolgenerator无业务耦合
01

defineTool 签名

等价于手写 { description: { type: "function", function: {...} }, execute, render }，只是省掉嵌套包装。

types.ts
defineTool(options: {
    name: string,        // 工具名，模型据此调用，同批工具内唯一
    description: string, // 给模型看的功能说明
    parameters: object,  // JSON Schema
    execute?: (args: object) => any | Promise<any>,
    render?:  (data: { args: object, result: any, status: string }) => any | Promise<any>
}): Tool
字段必填说明
name / description / parameters是组装进 description.function
execute(args)否页面侧执行，抛错会被捕获并记为 status: "error"
render(data)否execute 完成后的 UI 交互（弹窗确认、表单补充等），返回值才是回传给模型的最终结果
02

注册后的流转

  1. description 收入 tools_description，随 context.tools 发给服务端；
  2. 流中出现 caller: "frontend" 的 tool-call 时，页面执行 execute；
  3. 有 render 时，execute 结果先交给它做 UI 交互，其返回值经 ChatTransport.response("tool-result", ...) 回传服务端。
tools/showPlain.js
import { defineTool } from "@auipage/core";

export default defineTool({
    name: "showPlain",
    description: "显示文本文件中的内容",
    parameters: {
        type: "object",
        properties: {
            content: { type: "string", description: "需要显示的文本内容" }
        },
        required: ["content"]
    },
    async execute(args) {
        return args.content;        // 拿到原始结果
    },
    async render({ result }) {
        alert(result);              // 在 UI 上展示
        return "显示成功";           // 这才是回传给模型的结果
    }
});
省略 execute 只在 CreateTool 桥接场景下合法；直接本地跑 Agent 时，无 execute 的工具执行会报错。
03

generator 签名

types.ts
generator(
    rawFun: (
        next:  (value: any) => void,  // 推送一个值，可多次调用，按顺序消费
        done:  () => void,            // 结束
        error: (err: any) => void     // 报错，消费者侧会抛出
    ) => void
): AsyncGenerator<any>

rawFun 会被立即执行；done() / error() 之后再调 next() 会被忽略。 消费者提前退出（break / return()）时，后续 next() 同样被丢弃，队列会随之清空，不会一直堆在内存里0.2.0 改造。

04

generator 示例

接 Agent：它的流式更新走 logback / thinkback，包一层就是 AuiPage 需要的片段流：

adapter/chatTransport.js
import { generator, ChatTransportAdapter } from "@auipage/core";
import { Agent } from "@auipage/agent";

const agent = new Agent({
    model: { model: "gpt-4o-mini", apiKey: "sk-...", baseURL: "https://api.openai.com/v1" },
    stream: true
});

const chatTransport = new ChatTransportAdapter({
    run: ({ messages }) => generator((next, done, error) => {
        agent.generate(messages,
            text  => next({ type: "text", text }),
            think => next({ type: "thinking", text: think })
        ).then(done, error);
    })
});

任意回调式 API：事件发射器、定时器、文件读取都能包。

stream.js
import { generator } from "@auipage/core";

const stream = generator((next, done, error) => {
    emitter.on("data", next);
    emitter.on("end", done);
    emitter.on("error", error);
});

for await (const chunk of stream) {
    console.log(chunk);
}
消费者提前 break 不会通知生产者；底层连接需要手动关闭。
