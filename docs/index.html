02

两条接缝

适配器管数据，运行时管界面
Adapter

数据侧：接你的后端

对话怎么发、历史存哪、会话列表怎么读，全由三个适配器决定。 换模型服务、换数据库，改的是适配器，界面一行不动。

Runtime

界面侧：接你的 UI

会话列表与会话内容各有一个运行时基类，把状态变化翻译成渲染调用。 React / Vue / 原生 DOM 都是同一套接口的不同实现。

Tool

工具：前后端同一套描述

带 execute 的工具在服务端执行，不带的下发到浏览器， 结果回灌模型继续生成。CreateTool 负责这条往返。

03

一条消息走完的路

flow
用户输入
   │
   ├─ ChatTransportAdapter.run()      发起一轮对话，返回 AsyncGenerator
   │      ▲  这里可以放任何东西：Agent、官方 SDK、甚至一个假的流
   │      │
   │      └─ Agent.generate()          模型请求 → 工具调用 → 结果回灌 → 继续生成
   │             ├─ Model.completions()  SSE 增量、推理过程、tool_calls
   │             └─ fetch()             跨端流式读取 + SSE 事件切分
   │
   ├─ 片段逐条 yield 给 AuiPage
   │      ├─ text / thinking    → ChatContentRuntime 增量拼接
   │      ├─ tool-call（前端）  → 下发页面，挂起等待结果回传
   │      └─ tool-call（后端）  → 已执行完，直接展示结果
   │
   └─ MessageHistoryAdapter.append()   整组消息落库
