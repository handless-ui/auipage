agent web app framework

把对话、流式、工具调用
串成一条链路。

auipage 是智能体网页应用的开发框架：用「适配器 + 运行时」把大模型对话、流式输出、 工具调用、会话与历史管理串成一条链路。业务侧只对接模型与存储、只管 UI 渲染， 不用处理流式拼接和前后端工具桥接。

01

两层接缝

适配器管数据，运行时管界面
Adapter

适配器：接你的后端

对话怎么发、历史存哪、会话列表怎么读，全由三个适配器决定。 换模型服务、换数据库，改的是适配器，核心与界面一行不动。

Runtime

运行时：接你的界面

会话列表与会话内容各有一个运行时基类，把状态变化翻译成渲染调用。 React / Vue / 原生 DOM 都是同一套运行时接口的不同实现。

Tool

工具：前后端同一套描述

CreateTool 把服务端工具调用桥接到页面：带 execute 的在服务端跑， 不带的下发到浏览器执行，结果回灌模型继续生成。

02

五个包

包作用
@auipage/types跨包共用的类型协议：模型配置、消息、工具、流式事件。零运行时代码。
@auipage/fetch跨端流式 fetch：Node 走 http，浏览器走原生 fetch，SSE 自动按事件解析。
@auipage/modelOpenAI 风格 chat/completions：请求拼装、SSE 增量解析、工具调用切片拼接。
@auipage/agent对话循环：多轮工具调用编排、思维链回调、CreateTool 前后端桥接。
@auipage/core核心层：AuiPage + 三个 Adapter + 两个 Runtime + defineTool / generator。
03

一条消息走完的路

flow
用户输入
   │
   ├─ ChatTransportAdapter.run()      发起一轮对话，返回 AsyncGenerator
   │      ▲
   │      │  Agent.generate()          模型请求 → 工具调用 → 结果回灌 → 继续生成
   │      │      ├─ Model.completions()   SSE 增量、推理过程、tool_calls
   │      │      └─ fetch()              跨端流式读取 + SSE 事件切分
   │
   ├─ 片段逐条 yield 给 AuiPage
   │      ├─ text / thinking    → ChatContentRuntime 增量拼接
   │      ├─ tool-call（前端）  → 下发页面，挂起等待结果回传
   │      └─ tool-call（后端）  → 已执行完，直接展示结果
   │
   └─ MessageHistoryAdapter.append()   整组消息落库
