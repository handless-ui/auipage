Package 11@auipage/core

核心层：业务侧实现 Adapter 对接模型与存储，UI 侧实现 Runtime 负责渲染，AuiPage 把两者串起来，统一处理会话、历史、流式对话与入库。

01

最小装配

一个 AuiPage，三个适配器按固定 key 组合，两个运行时按固定 key 组合。实例会按 name 去掉后缀后挂载，例如 ChatTransportAdapter → page.adapter.ChatTransport。

main.js
import { AuiPage } from "@auipage/core";

const page = new AuiPage({
    adapter: {
        ChatTransport:  chatTransport,     // ChatTransportAdapter
        MessageHistory: messageHistory,    // MessageHistoryAdapter
        ThreadList:     threadList          // ThreadListAdapter
    },
    runtime: {
        ThreadList:  threadListUI,         // ThreadListRuntime
        ChatContent: chatUI                // ChatContentRuntime
    },
    tools: []                              // 可选：页面侧工具
});
构造后立即调用 ThreadList.list()，结果传给 ThreadListRuntime.init()。 挂载后的每个实例上会写入 aui，反向指向页面实例。
02

导出

导出类型作用
AuiPage构造器框架核心，管理 adapter / runtime、消息与会话状态
ChatTransportAdapter适配器基类对接模型对话接口，流式产出消息片段
MessageHistoryAdapter适配器基类历史消息的加载与追加
ThreadListAdapter适配器基类会话列表的增删改查
ThreadListRuntime运行时基类会话列表的 UI 渲染钩子
ChatContentRuntime运行时基类对话内容的 UI 渲染钩子
defineTool函数定义前端工具（name / description / parameters / execute / render）
generator函数把回调式异步流转成 AsyncGenerator
toModelMessages0.2.0 新增函数把页面消息（含工具调用与结果）转成模型入参，用于拼多轮上下文
MessageStream构造器服务端消息流封装（send / end），配合 CreateTool 推 SSE

两条接缝

Adapter

数据侧：三个接口

ChatTransport 产出流片段，MessageHistory 读写历史， ThreadList 管理会话。方法可以返回 Promise，也可以直接返回同步值； 没有实现的方法不会被调用0.2.0 修复。

04

MessageStream

server.js
import { MessageStream } from "@auipage/core";

const ms = new MessageStream(
    data => res.write("data: " + JSON.stringify(data) + "\n\n"),  // send 的落点
    () => res.end()                                                 // end 的落点
);

它只做一件事：把“要推给页面的数据”抽象成可 send 的对象。 前端工具挂起时，CreateTool 通过它把事件写进 SSE。换成 WebSocket，只要换这两个函数。

05

这个包不是必须的

你的情况更合适的选择代价
只做一个 React 聊天页assistant-ui、Vercel AI SDK 的 useChat状态与组件绑定，换框架要重写
不需要会话列表和历史自己维护消息数组 + 渲染循环流式拼接、工具状态要自己管
已有内部聊天框架复用内部框架，只在服务端接 @auipage/model没有跨端复用
UI 极简、只要文本自己写 AsyncGenerator + 渲染没有会话/历史/工具的统一流程

判断标准：如果你预计会换一次 UI 框架，或服务端要同时喂 Web 和桌面端，把流程抽出来才划算。
