Package 13Adapter 与 Runtime

两条接缝的全部接口：Adapter 负责数据，Runtime 负责渲染。框架只规定方法，缺省的方法不会被调用；返回值可以是 Promise，也可以直接是同步值0.2.0 修复；你可以 new 一个基类传实现，也可以写子类。

3 Adapter2 Runtime可继承
01

挂载规则

框架按实例的 name 属性去掉 Adapter / Runtime 后缀后挂载。基类已内置默认 name（默认为构造器名），子类可覆盖以改变挂载位置；实例上的 aui 反向指向所属 AuiPage。

02

ChatTransportAdapter

对接模型对话接口，sendMessage 时调用一次。

types.ts
new ChatTransportAdapter({
    // 返回异步生成器，逐个 yield 消息片段；返回假值则本轮中止
    run: (params: {
        messages: ChatMessage[],   // 本轮新消息（当前只有一条）
        context: {
            history: HistoryMessageGroup[],       // 已入库的历史消息组
            tools: Array<{ description: object }>,// 注册的工具描述
            signal?: AbortSignal                  // 取消信号（0.2.0 新增）
        }
    }) => AsyncGenerator<MessagePart> | void,

    // 页面 → 服务端回传通道，目前只回传前端工具结果
    response: (name: "tool-result", data: { id: string, status: string, result: any }) => any
});

yield 的片段分两类：{ type: "text" | "thinking" | "loading", text } 与 { type: "tool-call", status, id, name, caller, args, result? }。

adapter/chatTransport.js
import { ChatTransportAdapter, generator } from "@auipage/core";
import { Agent } from "@auipage/agent";

const agent = new Agent({
    model: { model: "gpt-4o-mini", apiKey: "sk-...", baseURL: "https://api.openai.com/v1" },
    stream: true
});

const chatTransport = new ChatTransportAdapter({
    run: ({ messages, context }) => generator((next, done, error) => {
        // 需要历史时，把 context.history 里的消息组合进来
        agent.generate(messages,
            text  => next({ type: "text", text }),
            think => next({ type: "thinking", text: think })
        ).then(done, error);
    }),

    response: (name, data) => fetch("/api/chat/" + name, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(data)
    })
});
03

MessageHistoryAdapter

types.ts
new MessageHistoryAdapter({
    load:   (threadId: string) => HistoryMessageGroup[] | Promise<...> | void,
    append: (threadId: string, group: HistoryMessageGroup) => any
});

load 返回假值时跳过历史加载；append 不实现则消息只留在内存。

入库的组带 status0.2.0 新增：complete 正常完成，stopped 被 page.stop() 主动结束，cancelled 被 page.cancel() 取消。这两种收尾照样调 append，存不存、怎么标由这里决定：stopped 当正常消息收下，cancelled 最省事的做法是整组丢掉。

adapter/messageHistory.js
const messageHistory = new MessageHistoryAdapter({
    load: (threadId) => {
        const raw = localStorage.getItem("history:" + threadId);
        return raw ? JSON.parse(raw) : [];
    },
    append: (threadId, group) => {
        const key = "history:" + threadId;
        const list = JSON.parse(localStorage.getItem(key) || "[]");
        list.push(group);
        localStorage.setItem(key, JSON.stringify(list));
    }
});
04

ThreadListAdapter

types.ts
new ThreadListAdapter({
    list:      () => Thread[] | Promise<Thread[]>,
    new:       (firstMessage: HistoryMessageGroup) => Thread | undefined | Promise<...>,
    delete:    (threadId: string) => any,
    archive:   (threadId: string) => any,
    unarchive: (threadId: string) => any
});

new 返回假值会中止本轮对话（不渲染会话、不写历史）；正常返回的对象至少含 threadId。

adapter/threadList.js
const threadList = new ThreadListAdapter({
    list:      () => fetch("/api/threads").then(r => r.json()),
    new:       firstMessage => fetch("/api/threads", {
                   method: "POST",
                   headers: { "Content-Type": "application/json" },
                   body: JSON.stringify(firstMessage)
               }).then(r => r.json()),
    delete:    threadId => fetch(`/api/threads/${threadId}`, { method: "DELETE" }),
    archive:   threadId => fetch(`/api/threads/${threadId}/archive`, { method: "POST" }),
    unarchive: threadId => fetch(`/api/threads/${threadId}/unarchive`, { method: "POST" })
});
05

ThreadListRuntime

会话列表（侧边栏）的渲染，共 6 个回调：

types.ts
new ThreadListRuntime({
    init:      (threads: Thread[]) => void,
    active:    (threadId: string | undefined) => void,
    append:    (thread: Thread) => void,
    delete:    (threadId: string) => void,
    archive:   (threadId: string) => void,
    unarchive: (threadId: string) => void
});
回调时机
initAuiPage 构造后，传入 ThreadList.list() 的结果
active切换会话；undefined 表示新建会话
append首轮对话创建新会话后
delete / archive / unarchive对应 adapter 方法成功后
runtime/threadList.js
const listEl = document.querySelector("#thread-list");
const nodes = new Map();   // threadId -> element

const threadListUI = new ThreadListRuntime({
    init: threads => {
        listEl.innerHTML = "";
        threads.forEach(renderOne);
    },
    active: threadId => {
        for (const [id, node] of nodes) {
            node.classList.toggle("active", id === threadId);
        }
    },
    append: renderOne,
    delete: threadId => {
        nodes.get(threadId)?.remove();
        nodes.delete(threadId);
    },
    archive:   id => nodes.get(id)?.classList.add("archived"),
    unarchive: id => nodes.get(id)?.classList.remove("archived")
});

function renderOne(thread) {
    const el = document.createElement("div");
    el.textContent = thread.title || thread.threadId;
    el.onclick = () => threadListUI.aui.activeThread(thread.threadId);
    listEl.appendChild(el);
    nodes.set(thread.threadId, el);
}
06

ChatContentRuntime

对话内容的渲染，只有两个回调，但 append 的返回值语义需要特别注意：

types.ts
new ChatContentRuntime({
    init:   (messages: ChatMessage[]) => void,   // 已拍平的消息片段数组
    append: (role: string, part: MessagePart) =>
        ((text: string) => void) | ((data: ToolCallPart) => any) | void
});

init 在切换会话时触发（新建会话传 []），业务侧需重建整个对话区域。

片段append 的返回值后续怎么用
text / thinking / loading更新函数 (text) => void后续增量通过它推送；返回 undefined 表示只建节点不追加
tool-call（pending）结束回调后端工具在 success / error 时调一次；前端工具有 render 时调两次
文本更新函数只在当前分段内有效，不要跨分段复用；工具结束回调按 id 缓存到 success / error 为止。
runtime/chatContent.js
const chatEl = document.querySelector("#chat-content");

const chatUI = new ChatContentRuntime({
    init: messages => {
        chatEl.innerHTML = "";
        messages.forEach(({ role, content }) =>
            content.forEach(part => renderPart(role, part))
        );
    },
    append: (role, part) => {
        const node = renderPart(role, part);

        if (part.type === "text" || part.type === "thinking" || part.type === "loading") {
            return text => {                 // 后续增量只更新这一个节点
                node.textContent += text;
                chatEl.scrollTop = chatEl.scrollHeight;
            };
        }

        if (part.type === "tool-call") {
            return finalPart => updateCard(node, finalPart);   // 更新卡片状态
        }
    }
});
