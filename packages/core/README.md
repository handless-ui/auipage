# [@auipage/core](https://github.com/handless-ui/auipage/packages/core/README.md)

auipage 的核心层：业务侧实现 Adapter 对接模型与存储，UI 侧实现 Runtime 负责渲染，`AuiPage` 把两者串起来，统一处理会话列表、消息历史、流式对话和历史入库。不耦合任何模型服务与 UI 框架。
